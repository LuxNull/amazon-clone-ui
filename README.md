# E-commerce Product Page & Cart

A simple e-commerce layout featuring a product grid, a detailed product page, and a functional shopping cart built with vanilla JavaScript.

## Tech stack
- HTML
- CSS
- JavaScript

## Features
- Product listing with hover effects
- Detailed product specification page
- Functional shopping cart (add, remove, update quantity)
- Localized currency and pluralization formatting

## How to run
Just open the `index.html` file in any browser.
